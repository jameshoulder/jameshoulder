## Hi, I'm James

I'm a UK-based IT Manager and MSc Digital & Technology Solutions student specialising in cyber security. I run IT in a manufacturing environment and build practical experience in securing systems, cloud infrastructure and networks.

I enjoy understanding how systems work, making them safer, and explaining the decisions behind the changes.

### Building DNS Daddy

[**DNS Daddy**](https://github.com/jameshoulder/dnsdaddy) is my free, open-source, self-hosted protective DNS project. It brings together network policies, threat intelligence, query investigation and the evidence behind DNS decisions.

It's also where I put secure development, vulnerability management and defensive engineering into practice. The project is **alpha, AI-assisted and not independently security-audited**; its source, limitations and assurance evidence are available to inspect.

[Explore the project](https://dnsdaddy.dev) · [Try the synthetic demo](https://demo.dnsdaddy.dev) · [Threat Observatory](https://threats.dnsdaddy.dev) · [Read the source](https://github.com/jameshoulder/dnsdaddy)
